# Modelo de ficha de personagem

Status: em desenvolvimento.

Use este modelo para protagonistas, heróis recrutáveis, antagonistas, narrador e coadjuvantes. Copie apenas o bloco Markdown abaixo para `docs/terminus/personagens/<id>.md` e preencha os campos entre colchetes. Os links dentro do bloco são relativos à pasta `personagens/`; mantenha-os ao criar a ficha e acrescente-a ao [índice do elenco](personagens/README.md).

O jogo não terá dublagem: o jeito de falar precisa aparecer nas palavras e na construção das frases. Ao usar um adjetivo como “gentil” ou “arrogante”, registre como isso se manifesta no diálogo. “Voz grave” não orienta a escrita; tamanho das frases, escolha de palavras e maneira de responder orientam.

Use a [visão do jogo](visao-do-jogo.md) para conferir as decisões de Terminus. Referências externas, interpretações e propostas devem permanecer identificadas até sua validação. Marque campos que não se aplicam ao personagem; não invente informações apenas para completar a ficha.

## 3. Assinatura de fala escrita

Descreva padrões que possam orientar a escrita de uma fala nova. Um bordão pode reforçar a identidade, mas não deve ser sua única marca.

| Aspecto | Direção de escrita |
| --- | --- |
| Tom predominante | [Que atitude transmite? Como as palavras tornam isso perceptível?] |
| Vocabulário | [Quais palavras prefere? Usa linguagem concreta, termos técnicos, expressões populares?] |
| Formalidade | [Como constrói uma conversa casual? Quando fica mais ou menos formal?] |
| Tratamento dos outros | [Como chama alguém, faz referência a si e estabelece proximidade ou distância?] |
| Comprimento das frases | [Tende a respostas curtas ou desenvolve explicações? Quando muda?] |
| Construção das frases | [Vai direto ao assunto, justifica antes de responder, faz perguntas, corrige o próprio raciocínio?] |
| Ritmo de leitura | [Como usa pausas, interrupções, repetições e hesitações?] |
| Humor | [Como faz graça ou reage ao humor dos outros? Pode não fazer graça.] |
| Comparações e referências | [A que experiências ou assuntos recorre para explicar o mundo?] |
| Trejeitos verbais | [Que hábitos aparecem na maneira de começar, desenvolver ou terminar uma fala?] |

### Conferência após o preenchimento

- [ ] As falas têm marcas reconhecíveis sem nome, retrato ou áudio.
- [ ] Os traços de personalidade aparecem nas escolhas de escrita.
- [ ] A diferenciação vai além de trocar um bordão ou algumas palavras.
- [ ] As variações emocionais preservam a identidade do personagem.
- [ ] Grafias caricaturais e pontuação excessiva não sustentam a caracterização.
- [ ] A leitura continua clara e natural em uma conversa mais longa.
- [ ] As falas foram comparadas com as de outros personagens, especialmente os de estilo parecido.
