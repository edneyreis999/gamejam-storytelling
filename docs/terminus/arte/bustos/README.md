# Bustos de Terminus

Status: em desenvolvimento.

28 bustos disponíveis: 15 do lote inicial e 13 produzidos na continuação de 18/10/2026, a partir das imagens já presentes na pasta principal. Incluem as três formas de Neral. A expansão restante acompanha a chegada das versões finais.

Gerados com a ferramenta integrada `image_gen`. Direção: retratos do Coreto, contorno preto, sépia, pontilhado e hachuras; enquadramento até a cintura e fundo transparente. Os sprites da pasta principal e as fichas orientam a identidade. Tharok e Melia, do repositório `projectX/frontend/img/pictures/Portraits/Principal`, são as referências de acabamento.

Os arquivos abaixo são candidatos para avaliação do autor. Os registros JSON preservam os prompts exatos e as referências de cada geração. O [controle](controle.json) identifica a versão atual de cada busto.
