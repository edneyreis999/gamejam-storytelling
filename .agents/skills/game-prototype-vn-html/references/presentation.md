# Presentation contract

These are defaults for a constrained visual novel, to confirm against the game's direction.

- A scene has a static background, one active speaking bust and a lower dialogue box. Record the stage aspect ratio; keep editorial annotations outside the stage.
- Dialogue shows speaker name and the explicitly selected bust. Thoughts identify their owner and thought mode.
- A description uses one reusable central panel with a distinct frame, left-aligned text and no visible speaker name or additional bust. Preserve the scene and current bust behind it, dim them lightly and hide the lower box. The usual reading control advances it; it is not a dismissible system dialog.
- Record narrative authorship separately from temporal presence. A narrator describing the past does not automatically appear in that past. Return to a framing story only when the script explicitly changes temporal frame and background.
- Specify asset references, expression/pose changes, object appearance, retention, disappearance and movement as presentation data. A single object moving across the screen remains one image.
- A handover identifies the recipient, displays the object, then moves it toward that recipient. Reduced motion retains the recipient and a textual account without requiring animation.
- Retain essential meaning in text. Expressions reinforce rather than carry indispensable information. Avoid converting every thought to speech or every mentioned item to a standalone asset.
- Paginate deliberately for legibility; avoid tiny type. Small screens may reflow controls and text while retaining scene relationships.
- Missing art gets labeled provisional staging, never a silently substituted unrelated image. Existing assets require suitability and provenance checks.
- Provide a player view and an optional art-direction view. The latter names the scene, passage, temporal frame, background, bust, objects and links to production briefs.

A palette change or screen transition is an authored decision, not an automatic consequence of a paragraph break.
