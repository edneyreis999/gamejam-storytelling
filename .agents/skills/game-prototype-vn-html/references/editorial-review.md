# Editorial review protocol

## Inputs

Read `humanizer`, the game's narrative authority, character reading index and the sheet of every participant. Include surrounding passages, temporal frame, available choices and consequences. For established characters, follow the sheet's required source readings.

## Review

1. Read the complete conversation aloud mentally, including alternatives and failure/retry content.
2. Identify repetitive structures, abstract moral explanations, unnaturally complete arguments, exposition characters would not say and generic narrator commentary.
3. Compare vocabulary, rhythm, humor, formality, evasions and treatment of others with each character's sheet. Preserve differences between voices.
4. Verify who knows what, whether a thought is private, who narrates and whether the script implies an unapproved event.
5. Rewrite while preserving decisions, consequences and factual meaning. Retain intentional character mannerisms even if a general style heuristic flags them.
6. Re-read integrated changes with the final passage order and chosen busts. Check that an expression reinforces the line instead of contradicting it.

## Delegated work

When delegation is authorized, give one reviewer bounded responsibility and a separate review artifact or exclusive ownership of the narrative file. The main agent integrates runtime and staging. Record scene IDs, review coverage, important corrections, supporting character-sheet guidance and unresolved contradictions. The reviewer performs a second pass after integration.

Do not claim automatic detection proves a text was written by a human. The deliverable is natural, characterized writing and an auditable review.
