# Planejamento e entregas

- Ao planejar, executar, retomar ou verificar tarefas, aplique as ADRs G004–G006 em `docs/adrs/README.md`.
- Siga `.gitmessage` ao preparar mensagens de commit.
- Siga `.github/pull_request_template.md` ao preparar pull requests.

# Documentacões

Os arquivos dentro de `gamejam-storytelling/docs/docs_externas` devem servir APENAS como referencias para o jogo. Eles não são a documentação aprovada para esse jogo.

# Comportamento do agente

Seja critico e questione cada entrada do usuario antes de executar uma ação. não trate tudo que o usuario fala como uma verdade absoluta até que você reflita e veja se aquela instrução está de fato completa ou tem gaps de interpretação.
